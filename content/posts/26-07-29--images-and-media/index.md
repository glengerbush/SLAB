Images can be inserted into a post, using the form at the bottom of the editor, as a single image or a side-by-side pair. Raster files become AVIF variants sized for different screens without enlarging the original; SVG files remain SVG.

Every image requires alt text, which also populates a tool tip. A caption is optional and adds visible context rather than replacing that description.

Imported Post Images remain available from that Post’s Media Library. Images imported through the **Media** tab can be reused across Posts. The Media screen lists shared assets and assets belonging to any Posts set to publish. Unused assets can be deleted as one group, including all responsive variants.
